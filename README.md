# Calculadora Web

Este projeto usa Python, Flask, HTML e JavaScript.

**Autor:** Arthur Braga Mendes

Foi baseado no exemplo [projeto_calculadora_js_nav](https://github.com/VictorThomaz/projeto_calculadora_js_nav).

A calculadora faz soma, subtração, multiplicação e divisão.

## Como executar

Instale as dependências:

```bash
python -m pip install -r requirements.txt
```

Execute o programa:

```bash
python app.py
```

Depois, acesse http://127.0.0.1:5000.
